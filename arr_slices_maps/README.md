The primary function is to learn arrays, slices, and maps

Arrays are like lists. They store a collection of elements that are of the same type with a fixed length. 
An example of an array could be var fruits := [3]string {"Apples", "Mangoes", "Bananas"}. The size and type must always be declared on the right side even in the shorter variable method. We use curly braces to show the elements in the array.
Arrays are fixed in size meaning we cannot grow/shrink it

That is where slices come in, they are arrays under the hood. You don't have to declare the size and you can append elements to it. 

Maps are used to store key-value pairs.
